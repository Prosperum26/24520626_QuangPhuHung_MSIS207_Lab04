# MSIS207 Lab 04

Multi-route SPA (React Router v7), context form engine, full-stack React 19 + Express.

## Chạy Exercise

Mỗi project độc lập, chạy `npm` trong folder của nó. Cần Node 22 trở lên.

```bash
cd Exercise_Lab04
cp .env.example .env

cd client && npm install && npm run dev      # http://localhost:5173
cd ../server && npm install && npm run dev   # http://localhost:3001
```

Kiểm chứng: `npm test` và `npm run lint` (client), `npm test` (server).

Bài tập và kế hoạch: [Exercise_Lab04/TASK_DECOMPOSITION.md](Exercise_Lab04/TASK_DECOMPOSITION.md). Luật làm việc: [Agents.md](Agents.md).
